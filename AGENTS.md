# Arbeidsregler for Codex

- Les `PROJECT.md` før du foreslår eller gjennomfører endringer i prosjektet.
- Forklar viktige tekniske valg på en måte som passer en erfaren IT-prosjektleder som er ny som programmerer.
- Gjør små, fokuserte endringer og unngå endringer utenfor den avtalte oppgaven.
- Bruk Bun som package manager og runtime. Ikke bruk npm, Yarn eller pnpm.
- Kjør relevante tester og build etter kodeendringer.
- Forklar hensikt, konsekvenser og alternativer for nye dependencies før de installeres.
- Ikke legg secrets, passord, tokens eller lokale miljøfiler i Git.
- Ikke gjør Git-commits eller push til GitHub uten uttrykkelig beskjed fra brukeren.
- Oppdater `PROJECT.md` når prosjektets mål, omfang eller teknologistakk endres.
